# УПЭ Стоп для Android

Офлайн-помощник оператора: чек-лист, пошаговый режим, справочник, правила, тренажёр с историей, независимые таймеры, журнал и настройки. Содержание загружается только из общего `../data/stop-algorithm.json`.

## Сборка и установка

Нужны полный JDK 17 (с `javac`), Android SDK platform 35 и Gradle **8.11.1**. Версии из `gradle/libs.versions.toml` закреплены согласно ТЗ; обновлять их отдельно после проверки совместимости.

```bash
bash scripts/codex-android-setup.sh
source ~/.bashrc
# Если java установлена без javac, отдельно установите полный JDK 17.
gradle -p android assembleDebug
gradle -p android --no-daemon testDebugUnitTest lintDebug assembleDebug
python3 scripts/check-android-content.py
python3 android/check-apk.py
```

Если SDK не найден, создайте `android/local.properties`: `sdk.dir=/абсолютный/путь/к/android-sdk`. Для сборки в среде с HTTPS-прокси настройте proxyHost/proxyPort в пользовательском `~/.gradle/gradle.properties` и доверенные CA полного JDK; эти настройки в репозиторий не входят. Проверку TLS не отключать.

Локальный APK: `app/build/outputs/apk/debug/app-debug.apk`. На GitHub: PR → Checks → **Android APK** → Artifacts → **upe-stop-apk**. После слияния: [Releases](https://github.com/Nodensss/OSTANOV/releases/latest). Скачайте APK на телефон, откройте и разрешите установку из этого источника. Без CI-секретов подписи APK подписан временным debug-ключом; при смене ключа требуется переустановка с потерей локальных данных. Постоянная release-подпись включается четырьмя секретами из ТЗ.

Android Studio: File → Open → каталог `android/`; выберите JDK 17 и Gradle 8.11.1. Исполняемого wrapper в репозитории нет по условиям ТЗ. Если Studio не предлагает скачать Gradle по properties, выберите локальную установку Gradle 8.11.1 в Settings → Build Tools → Gradle.

## Архитектура

1. `data/model` повторяет JSON, включая `critical` и nullable `phaseId`.
2. `AlgorithmRepository` один раз в фоне читает asset и валидирует его.
3. Gradle подключает корневой `data/` как assets; копии JSON нет.
4. `domain/` — чистый Kotlin без Android: валидация, прогресс, таймеры, поиск, тренажёр, журнал.
5. Room v1 хранит отметки с временем, таймеры и попытки. Схема в `app/schemas/`.
6. DAO отдают `Flow`; `AppViewModel` объединяет их в `StateFlow`.
7. Compose читает состояние через `collectAsStateWithLifecycle`.
8. DataStore Preferences хранит настройки, без сервера и учётных записей.
9. `AppContainer` создаёт зависимости вручную и владеет coroutine scope для сохранений.
10. `TimerRepository` сериализует операции таймеров, сброс и смену тестового режима.
11. `AlarmManager` будит receiver; уведомления используют системный обратный хронометр.
12. `BootReceiver` и запуск приложения восстанавливают будильники по epoch-времени.
13. Compose Navigation сохраняет состояние вкладок; курсор, поиск и текущий вопрос переживают поворот.
14. Журнал строится чистой функцией с ресурсными подписями и передаётся `ACTION_SEND` / в буфер.
15. Все данные остаются на устройстве; INTERNET отсутствует, backup выключен.

## Обновление данных

Менять только `data/stop-algorithm.json` в отдельной задаче; сохранять стабильные ID операций. После изменения запускать unit-тесты и проверку контента. Неизвестные сохранённые ID не учитываются. Ошибки данных не исправляются внутри Android-кода: при загрузке показывается описание проблемы.

## Принятые решения

- Основа ветки — `ccr-12fd5a40-3xwmnp`, потому что ТЗ ещё отсутствует в `main`. В PR поэтому входят и исходные коммиты ТЗ, AGENTS и двух скриптов; веб-файлы не меняются.
- На экране таймеров доступны все таймеры из JSON. Он открывается из меню чек-листа.
- Времена хранятся в epoch ms; перевод часов устройства влияет на таймер, как следует из формул ТЗ. Задержанный после перезагрузки таймер фиксирует расчётный срок окончания, а не время следующего открытия приложения.
- Изменение тестового режима блокируется при работающем таймере и в UI, и в репозитории. Режим доступен только debug-сборке, влияет только на длительность.
- Для комбинаций звука/вибрации созданы отдельные каналы завершения: параметры уже созданного канала Android нельзя программно менять. Системные настройки пользователя имеют приоритет.
- В открытом приложении notification не дублирует звуковой сигнал: сигнал и вибрация подаются внутри приложения. Если уведомления запрещены, фонового уведомления не будет, сохранение окончания работает.
- Загрузка JSON и изменения Room идут вне UI-потока. Запись запускается сразу, без debounce; интерфейс подтверждает отметку после записи в Room. Ошибки хранения выводятся в snackbar.
- Порядок вариантов ответа сохраняется. Перемешивается только порядок вопросов. Уход с экрана не завершает попытку автоматически.
- В отчёт включены все операции, в том числе неотмеченные; дата в отметке добавляется для другого дня. Подписи отчёта находятся в `strings.xml`, доменный builder получает их через адаптер.
- Только тёмная тема, системные шрифты, XML-иконка; бинарные ресурсы и Gradle Wrapper не добавляются.
- Помимо `allowBackup=false`, для Android 12+ явно исключены все домены облачного резервирования и переноса на другое устройство. Системные панели на API 26 настраиваются через AndroidX без атрибутов более новых API.

## Расхождение примера ТЗ и данных

В ТЗ в качестве примера поиска указан `PV-10603`. В текущем JSON есть только `10603` (этап 8); позиции с префиксом `PV-` имеют другие номера. Поиск не придумывает синонимы оборудования: `10603` находится в реальных данных, а эквивалентность `pv-10603` / `PV-10603` проверяется на синтетической позиции. JSON не изменён.

## Проверка на телефоне

Полный сценарий на 15 минут — [ТЗ, раздел 15.3](../docs/android/TZ.md#153-сценарий-ручной-проверки-15-минут). Для ускорения таймеров включите debug-настройку «1 мин = 1 с»: длительности берутся из JSON и становятся 40/180 сек в текущих данных. Проверьте уведомления при закрытом приложении, перезагрузку, поворот, шрифт 200%, запрет уведомлений и режим полёта. Принудительная остановка приложения в системных настройках блокирует receivers до следующего ручного запуска — это ограничение Android, в отличие от удаления из недавних.
