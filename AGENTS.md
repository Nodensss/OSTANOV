# AGENTS.md

## Что в репозитории

- **Веб-приложение «УПЭ Стоп»** (Next.js, корень репозитория) — чек-лист остановки технологической линии УПЭ, справочник, тренажёр.
- **Android-приложение** (каталог `android/`, Kotlin + Jetpack Compose) — офлайн-помощник оператора при остановке. Полное ТЗ: [`docs/android/TZ.md`](docs/android/TZ.md).
- **Общие данные:** `data/stop-algorithm.json` — единственный источник этапов, операций, параметров, позиций, правил и вопросов для обоих приложений.

## Задача по Android

Если задача касается Android, прочитай `docs/android/TZ.md` целиком и выполняй его полностью: этапы 0–10 из раздела 12, пока не пройдут все автоматические критерии раздела 13. Вопросов не задавай: где ТЗ молчит, принимай решение и записывай его в `android/README.md`, раздел «Принятые решения».

## Обязательные правила

1. **Не придумывать содержание алгоритма.** Тексты операций, параметры, позиции, предупреждения, правила и вопросы берутся только из `data/stop-algorithm.json`. Не хардкодить их в коде или `strings.xml` и не добавлять своих шагов.
2. **Не менять `data/stop-algorithm.json`.** Если нашёл ошибку в данных — опиши её в PR.
3. **Не трогать веб-приложение** (`app/`, `components/`, `lib/`, `prisma/`, конфиги Next.js). Исключение — раздел «Android-приложение» в корневом `README.md`.
4. **Без бинарных файлов в коммитах:** никаких `.png`, `.jpg`, `.webp`, `.ttf`, `.jar`, `.jks`, `.keystore`. Иконки — векторные XML. Gradle Wrapper не добавлять.
5. **Без `android.permission.INTERNET`** — приложение работает полностью офлайн.
6. **Не отключать проверки ради «зелёной» сборки:** не удалять тесты, не выключать lint целиком. Подавлять конкретное предупреждение можно только с комментарием-обоснованием.
7. Строки интерфейса — на русском, в `res/values/strings.xml`.

## Окружение и команды

```bash
# Если нет gradle / Android SDK (ставит JDK 17+, SDK 35, Gradle 8.11.1, прописывает ANDROID_HOME в ~/.bashrc):
bash scripts/codex-android-setup.sh && source ~/.bashrc

# Сборка, тесты и lint Android (из корня репозитория):
cd android && gradle --no-daemon testDebugUnitTest lintDebug assembleDebug

# APK:
ls -la android/app/build/outputs/apk/debug/app-debug.apk
```

Если `ANDROID_HOME` не задан, создай `android/local.properties` со строкой `sdk.dir=<путь к SDK>` (по умолчанию `$HOME/android-sdk`). Файл в `.gitignore`.
